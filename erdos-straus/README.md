# Эксперимент: «трудные» простые для гипотезы Эрдёша–Штрауса

Гипотеза: для любого n ≥ 2 существуют натуральные x, y, z, для которых 4/n = 1/x + 1/y + 1/z.

Морделл (1967) нашёл тождества, которые покрывают все n, кроме n ≡ 1, 121, 169, 289,
361, 529 (mod 840). Он же доказал, что полиномиальной формулы для этих классов
(квадратичных вычетов) быть не может. Эксперимент рассматривает именно эти простые.

## Метод

Для простого p ищем наименьшее t = 4x − p (t ≡ 3 mod 4), при котором остаток
t/(p·x) раскладывается в 1/y + 1/z. Раскладываем через тождество (ay − b)(az − b) = b²:
перебираем делители b². Каждое найденное решение проверяется точной арифметикой
дробей (`fractions.Fraction`).

Запуск: `python3 exp.py 10000000 results_1e7.json` (около 5 секунд).

## Результаты (p ≤ 10⁷)

- Трудных простых: **20 513**. Все разложены, все решения проверены.
- По шести классам простые распределены почти поровну (около 3 400 в каждом).
- Сколько трудных простых покрывает наименьшее t (нарастающим итогом):

| t | 3 | 7 | 11 | 15 | 19 | 23 | 31 | 59 | 107 |
|---|---|---|---|---|---|---|---|---|---|
| покрыто | 41,9% | 65,2% | 86,9% | 91,6% | 95,9% | 98,5% | 99,7% | ≈100% | 100% |

- Самое «упрямое» простое: **p = 8 803 369**, ему нужно t = 107:
  4/p = 1/2200869 + 1/181085300330 + 1/3293760527702370.
- У 98,5% решений оба знаменателя y и z делятся на p («тип II»).
- Внутри одного класса по модулю 840·11 случай t = 3 то работает, то нет (54 класса
  из 60). Успех зависит от разложения x на множители, а не только от остатка p.
  Это согласуется с теоремой Морделла.

## Наблюдение с доказательством (случай t = 3)

**Критерий:** для трудного простого p разложение с x = (p+3)/4 существует
**тогда и только тогда, когда у (p+3)/4 есть простой делитель q ≡ 2 (mod 3).**

Эмпирически: совпадение на всех 20 513 простых, исключений 0.

Доказательство. Все трудные классы дают p ≡ 1 (mod 3). Отсюда x = (p+3)/4 ≡ 1 (mod 3),
и b = p·x взаимно просто с 3. Нужен делитель d числа b², для которого d ≡ −b ≡ 2 (mod 3).
Все делители b² сравнимы с 1 по модулю 3 ровно тогда, когда все простые делители b
сравнимы с 1. Так как p ≡ 1, это условие на простые делители x. ∎

Это элементарный и, скорее всего, давно известный факт (частный случай классических
семейств решений). Новым результатом он не является. Но он наглядно показывает,
почему для трудных классов нужны условия на **разложение на множители**, а не на остаток.

## Возможные следующие шаги

1. Вывести такие же критерии для t = 7, 11, … (условия на делители (p+t)/4 по модулю t).
2. Оценить, какая доля простых не покрывается при t ≤ T. Если она убывает к нулю, это
   связано с известными результатами «почти все n» (Вон, Элсхольц–Тао).
3. Формализовать критерий для t = 3 в Lean.

## Lean-формализация (готово)

Файл [`lean/ErdosStrausT3.lean`](lean/ErdosStrausT3.lean): полное доказательство критерия для t = 3
в обе стороны, без `sorry`. Проверено на Lean 4.35.0 с Mathlib `56a0058`:

```
'ErdosStrausT3.criterion' depends on axioms: [propext, Classical.choice, Quot.sound]
'ErdosStrausT3.criterion_hard' depends on axioms: [propext, Classical.choice, Quot.sound]
```

- `criterion`: для простого p > 3, p ≡ 1 (mod 4):
  (∃ y z > 0, 4/p = 1/q + 1/y + 1/z) ⟺ (∃ простое r ∣ p·q, r ≡ 2 (mod 3)), где q = (p+3)/4.
- `criterion_hard`: при p ≡ 1 (mod 3) (все трудные классы) делитель r должен делить q.

Проверка: `lake env lean lean/ErdosStrausT3.lean` в любом проекте с Mathlib.

## Случай t = 7 (эксперимент и гипотеза-теорема)

Скрипт [`t7.py`](t7.py), p ≤ 10⁷. Здесь q = (p+7)/4, N = pq, и нужен делитель d ∣ N², для которого d ≡ −N (mod 7).

- p ≡ 3 или 6 (mod 7): t = 7 работает **всегда** (100% на всех простых p ≡ 1 mod 4).
  Подходит d = p или d = q. **Но трудных простых в этих классах нет**: трудные классы по модулю 840
  являются квадратичными вычетами по модулю 7, то есть p ≡ 1, 2, 4 (mod 7).
- Для трудных p (p ≡ 1, 2, 4 mod 7) t = 7 работает примерно в 39% случаев (8 045 из 20 513).

**Критерий:** для трудного p разложение с t = 7 существует ⟺ у q = (p+7)/4 есть простой делитель,
который является квадратичным невычетом по модулю 7 (≡ 3, 5, 6). Совпадение на 20 513 из 20 513.

Набросок доказательства. Для трудного p имеем p ≡ 1 (mod 8), значит q = (p+7)/4 чётно. Число 2 имеет порядок 3
по модулю 7, и делители 1, 2, 4 числа q² дают все вычеты {1, 2, 4}. Нужный остаток −N ≡ 5p² является невычетом.
(⇐) Если r ∣ q — невычет, то d = r·2ᵏ (k ≤ 2) пробегает все невычеты, один из них ≡ −N, и d ∣ q².
(⇒) Если невычетов среди простых делителей N нет (p — вычет), то все делители N² являются вычетами
и не могут быть ≡ −N. ∎

## t = 11, 19, 23: общий случай (скрипт [`tgen.py`](tgen.py), трудные p ≤ 10⁷)

Условие C: у N = p·q есть простой делитель, который является невычетом по модулю t (сюда входит и само p).

| t | работает | C да, работает | C да, НЕ работает | C нет, работает | C нет, не работает |
|---|---|---|---|---|---|
| 7  | 39,2% | 8 045  | **0**     | **0** | 12 468 |
| 11 | 65,4% | 13 417 | 787 (3,8%)  | **0** | 6 309 |
| 19 | 49,7% | 10 186 | 3 776 (18,4%) | **0** | 6 551 |
| 23 | 67,6% | 13 860 | 276 (1,3%)  | **0** | 6 377 |

- **C необходимо для любого простого t ≡ 3 (mod 4)** (0 исключений). Доказательство: если все простые делители N
  являются вычетами, то вычетами являются и все делители N², а −N — невычет, потому что −1 — невычет при t ≡ 3 (mod 4).
- Достаточность точна при t = 3 и t = 7, но **ломается** при t = 11, 19, 23. При t = 23 все 276 провалов
  имеют v₂(q) = 1.
- При t ≥ 11 остаток p по модулю t трудными классами не ограничен: примерно в половине случаев p само является
  невычетом. Поэтому при t = 11 и t = 23 метод работает чаще, чем при t = 7.
